Notifications

Overview​

The Notifications feature provides users with visibility into operational events generated by monitoring activities within ITOSS. Notifications are intended to highlight situations that require attention and facilitate timely response by operational support teams.

User Interface​

Notifications are accessible from the ITOSS user interface through the notification area located in the upper-right section of the application, adjacent to the search control.

Components​

  • Notification Icon: Represented by a bell symbol.
  • Notification Counter: Displays the number of active notifications currently available for the user.
  • Notification Panel: Presents the list of active notifications and allows users to review additional information associated with each event.

Notification Generation​

Notifications are generated by monitor execution logic.

A monitor may create a notification when a configured condition, threshold, or operational rule is satisfied and requires user attention. The notification mechanism serves as a communication channel between monitoring processes and operational users.

Notification Lifecycle​

Creation​

A notification is created when a monitor determines that a relevant operational condition has occurred.

Active State​

While active, notifications are displayed in the user's notification panel and contribute to the notification counter displayed in the user interface.

Expiration​

Notifications remain active for a maximum period of four hours.

After the retention period expires, notifications are automatically removed from the system. This behavior ensures that the notification panel contains only recent and operationally relevant information.

User Actions​

Dismiss Notification​

Users may dismiss an individual notification from their personal notification panel.

Clear All Notifications​

Users may clear all active notifications available in their notification view.

User Scope​

Notification management actions are user-specific:

  • Dismissing a notification affects only the current user.
  • Clearing notifications affects only the current user.
  • Notifications remain visible to other users until they independently dismiss them or the notification expires.

Operational Considerations​

  • Notifications are intended for operational awareness and event visibility.
  • Notification retention is limited to four hours.
  • Notification deletion due to expiration is automatic and permanent.
  • User actions on notifications do not impact the visibility of notifications for other users.
