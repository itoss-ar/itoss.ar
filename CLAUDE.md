## What this is

Marketing site + technical docs for **ITOSS** (an IT operations platform for MSPs), built on **Docusaurus 3.10.1**. Despite the `-v2` directory name and `docusaurus-v2` in paths, this is Docusaurus v3. Content is mixed Spanish/English; default i18n locale is `es`.

## Commands

```bash
npm install
npm start          # dev server at http://localhost:3000, hot reload
npm run build      # static build to /build
npm run serve      # serve the production build locally
npm run clear      # clear Docusaurus cache (.docusaurus) — use when builds act stale
npm run swizzle    # eject/override a theme component
```

There is no test runner, linter, or formatter configured. Node 18+ required.

## Architecture

Two surfaces share one design system:

- **Marketing pages** — React components under `src/pages/` (`index.js` home, `modules.js`, `services.js`, `contact.js`), rendered outside the docs routing. They compose section components from `src/components/site/Sections.js`, which pull synthetic demo data from `src/components/site/data.js`.
- **Docs** — Markdown under `docs/`, ordered by `sidebars.js`. The sidebar is largely a hand-maintained tree (not fully autogenerated); when you add a doc file you must also add its slug to `sidebars.js`, and the slug path is case-sensitive and must match the on-disk path.

### Design system (most important file: `src/css/custom.css`)

All branding flows from the `:root` token block in `src/css/custom.css`:
- ITOSS tokens (`--cyan`, `--lime`, `--brand-grad`, `--bg`/`--surface` surfaces, `--text-*` ramp) drive custom components.
- `--ifm-*` overrides re-skin Docusaurus's native (Infima) components.

Change brand colors/typography here, not in component files.

### Dark mode only

`colorMode` in `docusaurus.config.js` forces dark mode with `disableSwitch: true`. There is no light theme — don't add one or a toggle.

### SSR/hydration determinism (critical for animated components)

`Dashboard.js` and `LogStream.js` animate live-looking metrics/logs. They **must** initialize with deterministic values and only introduce randomness inside `useEffect`, otherwise server-rendered and client HTML mismatch and hydration breaks. Preserve this pattern in any new animated component.

### Hero variant

`Hero` in `Sections.js` supports layout variants (A=Split, B=Centered, C=Live logs). The home page (`src/pages/index.js`) is hardcoded to `variant="A"`; change that prop to switch layouts.

## Config touchpoints

- Navbar & footer links: `docusaurus.config.js` → `themeConfig.navbar` / `themeConfig.footer`.
- Broken links currently `warn` (not error) for both links and markdown links.
- Integration logos in `Sections.js` are placeholder `GenericIcon` glyphs; replace with real logos when available. All metrics/hosts/SLAs are synthetic demo data.
